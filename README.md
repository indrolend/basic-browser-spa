# basic-browser-spa

Current static web runtime for indrolend.com.

The root page loads the Indrolend catalog. `data/` contains the Digital Breakdown web/store surface. `drift/` contains the Endless Learning build.

## Run

```sh
python -m http.server 8000
```

Open `http://127.0.0.1:8000/`.

## Test

```sh
npm test
```
